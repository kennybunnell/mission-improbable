# Mission: Improbable

A playful, mobile-first couples mission control PWA. Book-first companion experience with QR-deep-link missions.

## Deploy
Import this repository into Vercel. It is a static web app and needs no build command.

## Demo
The initial version runs locally in a browser without account credentials. Real partner syncing and push notifications require Supabase and a notification service.

## Principles
Both agents can initiate, and a declined mission is always respected. Missions are invitations, never obligations.
