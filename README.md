# Mission: Improbable

A premium, playful couples command center PWA. Book-first, QR-friendly, and Vercel-ready.

## Deploy
Import this GitHub repository at https://vercel.com/new. Framework preset: Other. No build command or environment variables are required for demo mode.

## Demo features
Six interactive mission modes, a local mission log, editable agent code names, book companion, QR-friendly links at `/m/007`, `/m/014`, `/m/021`, `/m/032`, `/m/045`, `/m/059`, and installable web app support.

## Important
This first release is a single-device demo. Mission responses are simulated and saved locally; real couple pairing, partner notifications, and shared data require Supabase and a notification service. Never treat a mission as consent or an obligation.
